# Shreyansh ❤️ Alisha Proposal Website

## Deploy on GitHub Pages (free)
1. Create/sign into GitHub.
2. Create a **public repository**, e.g. `alisha-proposal`.
3. Upload ALL 6 files from this folder:
   - `index.html`
   - `question-1.html`
   - `question-2.html`
   - `question-3.html`
   - `style.css`
   - `script.js`
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Wait a little for deployment. GitHub will show the website URL.
8. Send the URL to Alisha.

### Important
Keep all files in the same folder/repository. The pages redirect to one another using relative links, so no server/database is required.

## Alternative
You can also upload the folder to any static-hosting provider that supports HTML/CSS/JS. No backend is needed.
